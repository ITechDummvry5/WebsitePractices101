Introduction to JavaScript

What is JavaScript?

  • It makes websites interactive.
  • It gives instructions to the computer. (Code)
  • The computer follows those instructions. (Running the code)

The 3 Technologies of the Web

  • HTML - Creates the structure of a webpage.
  • CSS - Styles the webpage.
  • JavaScript - Adds interactivity.

What is a Programming Language?

  • Similar to human languages, but written for computers.

JavaScript is Case-Sensitive

  • Hello and hello are different.
  • JavaScript treats uppercase and lowercase letters differently.

Syntax

  • Syntax is the set of rules for writing code.
  • Correct syntax allows the code to run without errors.
