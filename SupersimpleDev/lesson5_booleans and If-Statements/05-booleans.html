Booleans and Conditional Logic in JavaScript

Booleans are values that can only be true or false. They are commonly used when making decisions in JavaScript through comparisons, logical operations, and conditional statements.

1. Template Literals

A template literal always returns a string, regardless of the value placed inside it.

Input Value Resulting Type
Number String
Boolean String
Null String
Undefined String

2. Comparison Operators

Comparison operators compare two values and always return a boolean value (true or false).

Operator Name Description
> Greater Than Checks if the left value is greater than the right value.
< Less Than Checks if the left value is less than the right value.
>= Greater Than or Equal To Checks if the left value is greater than or equal to the right value.
<= Less Than or Equal To Checks if the left value is less than or equal to the right value.

3. Equality Operators

Equality operators determine whether two values are equal or not.

Operator Name Description
== Loose Equality Compares values after automatic type conversion.
!= Loose Inequality Checks if values are not equal after type conversion.
=== Strict Equality Compares both value and data type.
!== Strict Inequality Checks if either the value or data type is different.

Best Practice: Use === and !== because they compare both the value and the data type, making your code more predictable.

4. Truthy and Falsy Values

When used in a condition, every JavaScript value is treated as either truthy or falsy.

Falsy Values

Value
false
0
Empty String ("")
null
undefined
NaN

Truthy Values

Any value that is not falsy is considered truthy. Examples include:

Examples
true
Any non-zero number
Any non-empty string
Arrays
Objects

5. Ternary Operator

The ternary operator is a shorter way to write a simple if...else statement.

Syntax:

Condition ? ValueIfTrue : ValueIfFalse

const label = age >= 18 ? 'Adult' : 'Minor';

6. Logical Operators

Logical operators combine or modify conditions.

Operator Name Description
&& AND Returns true when all conditions are true.
|| OR Returns true when at least one condition is true.
! NOT Reverses a boolean value.

7. Conditional Statements

Conditional statements allow a program to make decisions based on whether a condition evaluates to true or false.

Statement Purpose
if Runs code when a condition is true.
else if Checks another condition if the previous one is false.
else Runs when none of the previous conditions are true.

Summary

  • Comparison operators compare values.
  • Equality operators check whether values are equal.
  • Truthy and falsy values determine how conditions are evaluated.
  • The ternary operator provides a short form of an if...else statement.
  • Logical operators combine or modify conditions.
  • Conditional statements allow programs to make decisions.
