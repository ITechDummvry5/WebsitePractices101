Functions

Functions are reusable blocks of code that can be called with different arguments to perform specific tasks. They help organize code, reduce repetition, and improve readability.

Parameters

Parameters are variables used to pass information into functions. They act as placeholders for the values provided when the function is called.

Parameter = a placeholder variable in the function definition.
Argument = the actual value passed when calling the function.
Parameters → put a value into a function.
Return → get a value out of a function.

Syntax Rules for Parameters

Basic Rules:

  • Cannot use special characters (e.g., @, #, $).
  • Cannot use reserved keywords (e.g., function, var).
  • Cannot start with a number.
  • Cannot use the parameters outside of the function scope.

Advanced Rules:

  • Defined within parentheses (e.g., function greet(name) { }).
  • Can have default values (e.g., function greet(name = "Guest") { }).
  • Can accept any data type (e.g., "John" | String, 25 | Number, true | Boolean).
  • Can have multiple parameters (e.g., function multiplePet(dog, cat, fish) { }).

Best Practices:

  • Use camelCase (e.g., firstName, totalPrice).
  • Use descriptive names (e.g., length, width).
  • Keep the number of parameters to a minimum (e.g., createUser(name, age)).
  • Group related parameters with an object (e.g., createUser({ name, age })).
