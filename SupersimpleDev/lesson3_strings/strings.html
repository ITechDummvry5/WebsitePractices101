Lesson 3 — Strings

What is a String?

A string is text. Numbers and strings are different types of values in JavaScript. 

typeof 2;        // "number"
typeof "hello";  // "string"

Order of Operations

String expressions follow the same operator precedence as numbers.

  • Parentheses ( ) are evaluated first.
  • * and / have higher precedence than + and -.
  • * and / are evaluated from left to right.
  • + and - are evaluated from left to right.

The 4 Ways to Create a String

The 4 Ways to Create a String

Type Syntax Purpose Example
Single Quotes ' ' Create a normal string 'Hello World'
Double Quotes " " Useful when the string contains single quotes "I'm learning JavaScript"
Escape Characters \', \", \n, \t, \\ Add special characters inside strings 'I\'m learning\nJavaScript'
Template Strings ` ` Create strings with variables, expressions, and multiple lines `Hello ${name}`

Template String SPECIAL Feature: Interpolation

Interpolation is a feature inside Template Strings. It allows you to insert variables or expressions directly into a string using ${}. 

const name = "John";

const message = `Hello ${name}`;

console.log(message);

// Output:
// Hello John

Remember:

  • Template String = The string created using backticks ` `
  • Interpolation = The feature inside a template string using ${}

Concatenation and Type Coercion

'Hello' + 'World'   // "HelloWorld"
'Hello' + 2         // "Hello2"

When a string is combined with a number using the + operator, JavaScript automatically converts the number into a string.

This automatic conversion is called Type Coercion.
