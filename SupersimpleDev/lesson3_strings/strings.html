Lesson 3 — Strings

What is a String?

A string is text. Numbers and strings are different types of values in JavaScript. 

typeof 2;        // "number"
typeof "hello";  // "string"

Order of Operations

String expressions follow the same operator precedence as numbers.

  • Parentheses ( ) are evaluated first.
  • * and / have higher precedence than + and -.
  • * and / are evaluated from left to right.
  • + and - are evaluated from left to right.

The 4 Ways to Create a String

  • Single Quotes — 'Hello'
  • Double Quotes — "Hello"
  • Escape Characters — \', \", \n, \t, \\
  • Template Strings — `Hello`

Concatenation and Type Coercion

'Hello' + 'World'   // "HelloWorld"
'Hello' + 2         // "Hello2"

When a string is combined with a number using the + operator, JavaScript automatically converts the number into a string.

This automatic conversion is called Type Coercion.
