Numbers and Math in JavaScript

Numbers in JavaScript

  • JavaScript has two types of numbers: integers and floats.
  • Integers are whole numbers (e.g., 5, -10).
  • Floats are decimal numbers (e.g., 3.14, -2.5).

Mathematical Operators

  • Addition: +
  • Subtraction: -
  • Multiplication: *
  • Division: /
  • Modulus: % (returns the remainder)

Order of Operations (Operator Precedence)

JavaScript follows the standard order of operations (PEMDAS/BODMAS).

  • * and / are done first
  • + and - are done after
  • * and / have the same priority and are evaluated from left to right
  • + and - have the same priority and are evaluated from left to right
Priority Operation Example
1st Parentheses ()
2nd Exponents **
3rd Multiplication and Division * /
4th Addition and Subtraction + -

Control the Order of Operations

Parentheses (( )) are used to group expressions and control the order of operations.

Example:

(5 + 3) * 2

Result is 16 because the expression inside parentheses is calculated first.

Calculate Percent

To calculate a percentage of a number, use this formula:

(percent / 100) * number

Example: 20% of 50

(20 / 100) * 50 = 10

Terminology

  • Integer: A whole number (e.g., 5, -10).
  • Float: A decimal number (e.g., 3.14, -2.5).
  • Operator: A symbol that performs an operation on one or more values (e.g., +, -, *, /).
  • Expression: A combination of values, variables, and operators that evaluates to a single value.

Problem in Floats

JavaScript uses floating-point arithmetic, which can lead to precision issues.

Example in console:

0.1 + 0.2

Result is 0.30000000000000004 instead of 0.3.

To avoid this, you can use:

  1. toFixed() – round to a fixed number of decimals
  2. Math.round() – round to nearest whole or adjusted value
  3. Convert to cents – multiply by 100, do math, then divide back to dollar

Simplified Explanation

  • Computers do not use decimal numbers like humans. They use a system called binary, which only uses 0 and 1.
  • Humans use decimal numbers: 0–9.
  • Computers use binary numbers: 0 and 1.

Example:

Decimal (Human) Binary (Computer)
0 0
1 1
2 10
3 11
4 100

This means computers convert all numbers into binary before storing or processing them.
